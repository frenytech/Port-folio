## 🚀 What is this?

FrenyTech HUD is a modern Heads-Up Display system built for gamers and developers in the zone.id ecosystem. Clean, fast, and customizable.

## ✨ Features

- 🎮 Real-time gaming overlay
- 📊 Live stats dashboard
- 🎨 Custom themes & layouts
- ⚡ Lightweight - < 2MB
- 🔧 Easy integration with any site
- 📱 Mobile responsive

## 🛠️ Tech Stack

- HTML5 / CSS3 / JavaScript
- Python (Backend)
- zone.id API
